# 🌱 Featured Project

## 🌿 Flora — AI-Powered Plant Disease Detection & Treatment Advisor

> **An AI-powered multi-crop plant disease detection and treatment recommendation system.**

Flora combines **Deep Learning, Computer Vision and Generative AI** to detect plant diseases from leaf images and provide intelligent treatment and prevention recommendations.

### ✨ Key Features

* 🌱 **Multi-crop plant disease detection**
* 🧠 Dedicated **Deep Learning model for each crop**
* 👁️ CNN-based **image classification**
* 🤖 AI-powered **treatment recommendations**
* 🧪 **Chemical & organic treatment suggestions**
* 🛡️ Disease **prevention tips**
* 🌿 Plant **care guidance**
* 🌍 **English, Hindi & Hinglish** support
* 💬 AI-powered **follow-up questions**
* 📄 **PDF report generation**
* 🖥️ Interactive **Streamlit web application**

### 🛠️ Tech Stack

```text
Programming:   Python
AI/ML:         TensorFlow • CNN • Deep Learning
GenAI:         LangChain • Groq • LLM
Frontend:      Streamlit
Data:          NumPy • Pandas
Deployment:    Flask / Streamlit
```

**Repository:**
👉 [Flora – Plant Disease Detection](https://github.com/Abhi-prajapat-i/flora-plant-disease-detection)
